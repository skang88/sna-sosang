# 2026 소상공인 연구논문 공모전 — 산청·하동 산불 이후 소상공인 지원 네트워크

2025년 산청·하동 산불 이후 소상공인·상권 지원 기관 네트워크를 지역 언론 보도(경남도민일보·경남일보 37건)로 분석한 공모전 원고와 관련 자료.

## v2 변경 사항 (Ⅰ·Ⅱ장, 참고문헌)

- Ⅰ장: '선행연구와 문제 제기'(소상공인 재난 회복 문헌, 국내 재난 거버넌스 네트워크 연구), '논문의 구성' 추가
- Ⅱ장: 7개 절로 재구성 — 소상공인 재난 회복과 지원 기관 / 조직 간 회복력 / 중심성·중앙화·중개 / 재난 단계와 네트워크 변화(연속 재난 포함) / 협력적 거버넌스와 수요자 조직 / 오션포트 선행 사례 / 선행연구 정리와 분석틀(〈표 2〉, 〈표 3〉에 연구 질문 대응)
- 추가 문헌 18편(국외 15, 국내 3), 전부 DOI 또는 공식 URL 확인
- 본문 인용을 APA 7판(`2017, p. 76`)으로 통일, 참고문헌 국내→국외 순 정렬, 인용-목록 일치 확인
- 표 번호 재정렬(표 1~9)

## Ⅲ·Ⅳ 담당자 확인 사항

- **이현민(Ⅲ)**: 〈표 3〉 분석틀의 측정 항목과 Ⅲ장의 지표가 일치하는지 확인. Ⅲ-5에 Gould & Fernandez(1989) 중개 유형을 넣을지 결정. Ⅲ-5의 "Python networkx" 문구를 R 사용으로 바꿀지 결정.
- **강석균(Ⅳ, R)**: 연결 중앙화·매개 중심성 재계산(`sna::centralization`, `sna::betweenness` 또는 `igraph`). 중개 유형은 `sna::brokerage`(Gould–Fernandez)로 계산 가능 — 그룹은 기관 수준(현지·경남·전국). 수치가 바뀌면 Ⅰ장 초록·Ⅳ·Ⅴ장 숫자도 함께 수정 필요.
- 공통: 참고문헌의 Jones & Faas(2017) 편저 장(6장 Harris & Doerfel, 4장 Varda, 17장 Maldonado) 쪽수 `pp. ○–○` 기입 필요.
